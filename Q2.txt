Salary) from a user. Write JDBC program to perform following operations: 
i. Store employee details into the Employee table.  
ii. Display all details of Employee from the table. 

short and easy without skipping any line

Here is a short and easy JDBC Java program (with all lines, nothing skipped):

✅ Java Program: Insert + Display Employee Data using JDBC
import java.sql.*;
import java.util.Scanner;

public class EmployeeJDBC {
    public static void main(String[] args) {
        try {
            // Load Driver
            Class.forName("com.mysql.cj.jdbc.Driver");

            // Create Connection
            Connection con = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/test", "root", "root");

            Scanner sc = new Scanner(System.in);

            // Accept Employee Details
            System.out.print("Enter Employee No: ");
            int eno = sc.nextInt();
            sc.nextLine();

            System.out.print("Enter Employee Name: ");
            String name = sc.nextLine();

            System.out.print("Enter Designation: ");
            String desig = sc.nextLine();

            System.out.print("Enter Salary: ");
            double salary = sc.nextDouble();

            // Insert Data
            PreparedStatement ps = con.prepareStatement(
                "INSERT INTO Employee VALUES (?, ?, ?, ?)");
            ps.setInt(1, eno);
            ps.setString(2, name);
            ps.setString(3, desig);
            ps.setDouble(4, salary);

            int i = ps.executeUpdate();
            if (i > 0) {
                System.out.println("Record Inserted Successfully");
            }

            // Display Data
            Statement st = con.createStatement();
            ResultSet rs = st.executeQuery("SELECT * FROM Employee");

            System.out.println("\nEmployee Details:");
            while (rs.next()) {
                System.out.println(
                    rs.getInt(1) + " " +
                    rs.getString(2) + " " +
                    rs.getString(3) + " " +
                    rs.getDouble(4)
                );
            }

            // Close Connection
            con.close();

        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

import java.awt.*;
import javax.swing.*;

public class BlinkText extends JFrame implements Runnable {

    JLabel label;
    Thread t;

    public BlinkText() {
        label = new JLabel("Blinking Text", JLabel.CENTER);
        add(label);

        setSize(300, 200);
        setVisible(true);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

        t = new Thread(this);
        t.start();
    }

    public void run() {
        try {
            while (true) {
                label.setVisible(true);
                Thread.sleep(500);

                label.setVisible(false);
                Thread.sleep(500);
            }
        } catch (Exception e) {
            System.out.println(e);
        }
    }

    public static void main(String[] args) {
        new BlinkText();
    }
}

Q5.  Write a program that implements a multi-thread application that has three threads. First 
thread generates random integer after every 1 second and if the value is even, second 
thread computes the square of the number and prints. If the value is odd, the third 
thread will print the value of cube of the number. 

short and easy without skipping any line

Here is a short and easy multi-thread Java program (complete, no lines skipped):

✅ Java Program: Three Threads (Even → Square, Odd → Cube)
import java.util.Random;

class Number extends Thread {
    public void run() {
        try {
            Random r = new Random();

            while (true) {
                int num = r.nextInt(100);
                System.out.println("Generated Number: " + num);

                if (num % 2 == 0) {
                    new Square(num).start();
                } else {
                    new Cube(num).start();
                }

                Thread.sleep(1000);
            }
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

class Square extends Thread {
    int n;

    Square(int n) {
        this.n = n;
    }

    public void run() {
        System.out.println("Square of " + n + " is " + (n * n));
    }
}

class Cube extends Thread {
    int n;

    Cube(int n) {
        this.n = n;
    }

    public void run() {
        System.out.println("Cube of " + n + " is " + (n * n * n));
    }
}

public class MultiThreadDemo {
    public static void main(String[] args) {
        Number t = new Number();
        t.start();
    }
}
🧠 Important Points (for exam)
Thread 1 (Number) → generates random number every 1 sec

Thread 2 (Square) → runs if number is even

Thread 3 (Cube) → runs if number is odd

import java.sql.*;

public class DonarMetaData {
    public static void main(String[] args) {
        try {
            // Load Driver
            Class.forName("com.mysql.cj.jdbc.Driver");

            // Create Connection
            Connection con = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/test", "root", "root");

            Statement st = con.createStatement();

            // Execute Query
            ResultSet rs = st.executeQuery("SELECT * FROM Donar");

            // Get MetaData
            ResultSetMetaData rsmd = rs.getMetaData();

            int cols = rsmd.getColumnCount();

                System.out.println("Column Size: " + rsmd.getColumnDisplaySize(i));
                System.out.println("---------------------------");
            }

            // Close Connection
            con.close();

        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

import java.sql.*;
import java.util.Scanner;

public class EmployeePrepared {
    public static void main(String[] args) {
        try {
            // Load Driver
            Class.forName("com.mysql.cj.jdbc.Driver");

            // Create Connection
            Connection con = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/test", "root", "root");

            Scanner sc = new Scanner(System.in);

            // Accept Employee Details
            System.out.print("Enter Id: ");
            int id = sc.nextInt();
            sc.nextLine();

            System.out.print("Enter Name: ");

            System.out.print("Enter Salary: ");

            PreparedStatement ps = con.prepareStatement(
                "INSERT INTO Employee VALUES (?, ?, ?)");

            ps.setString(2, name);

            System.out.println("\nEmployees whose name starts with A:");
            while (rs.next()) {
                System.out.println(
                    rs.getInt(1) + " " +
                    rs.getString(2) + " " +

            // Close Connection
            con.close();

        } catch (Exception e) {

Q12. Write a SERVLET program which counts how many times a user has visited a web 
page. If user is visiting the page for the first time, display a welcome message. If the 
user is revisiting the page, display the number of times visited. (Use Cookie)

short and easy without skipping any line

Here is a short and easy Servlet program using Cookie (complete, no lines skipped):

✅ Servlet Program (VisitCountServlet.java)
import java.io.*;
import javax.servlet.*;
import javax.servlet.http.*;

public class VisitCountServlet extends HttpServlet {

    public void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {

        response.setContentType("text/html");
        PrintWriter out = response.getWriter();

        int count = 0;

        // Get Cookies
        Cookie[] cookies = request.getCookies();
        boolean found = false;

        if (cookies != null) {
            for (int i = 0; i < cookies.length; i++) {
                if (cookies[i].getName().equals("visit")) {
                    count = Integer.parseInt(cookies[i].getValue());
                    found = true;
                    break;
                }
            }
        }

        if (found) {
            count++;
            out.println("<h2>You have visited " + count + " times</h2>");
        } else {
            count = 1;
            out.println("<h2>Welcome! This is your first visit</h2>");
        }

        // Create/Update Cookie
        Cookie c = new Cookie("visit", String.valueOf(count));
        response.addCookie(c);
    }
}
🧠 Important Points (for exam)
Uses Cookie to store visit count

request.getCookies() to read cookies

response.addCookie() to update cookie

First visit → Welcome message

Next visits → count increases

Q13. Construct a linked List containing names of colours: red, blue, yellow and orange. 
Write a menu driven program to do the following:   
a. Display the contents of the List using an Iterator  
b. Display the contents of the List in reverse order using a ListIterator   
c. Create another list containing pink and green. Insert the elements of this list  
between blue and yellow

short and easy without skipping any line

Here is a short and easy Java program (menu-driven, LinkedList) — complete, no lines skipped:

✅ Java Program: LinkedList Operations
import java.util.*;

public class ColorList {
    public static void main(String[] args) {

        LinkedList<String> list = new LinkedList<String>();

        // Add initial colors
        list.add("red");
        list.add("blue");
        list.add("yellow");
        list.add("orange");

        Scanner sc = new Scanner(System.in);
        int choice;

        do {
            System.out.println("\n1.Display using Iterator");
            System.out.println("2.Display in Reverse");
            System.out.println("3.Insert new colors");
            System.out.println("4.Exit");
            System.out.print("Enter choice: ");
            choice = sc.nextInt();

            switch (choice) {

                case 1:
                    Iterator<String> it = list.iterator();
                    System.out.println("List:");
                    while (it.hasNext()) {
                        System.out.println(it.next());
                    }
                    break;

                case 2:
                    ListIterator<String> lit = list.listIterator(list.size());
                    System.out.println("Reverse List:");
                    while (lit.hasPrevious()) {
                        System.out.println(lit.previous());
                    }
                    break;

                case 3:
                    LinkedList<String> list2 = new LinkedList<String>();
                    list2.add("pink");
                    list2.add("green");

                    int index = list.indexOf("yellow");
                    list.addAll(index, list2);

                    System.out.println("After Insertion:");
                    System.out.println(list);
                    break;

                case 4:
                    System.exit(0);
            }

        } while (true);
    }
}
🧠 Important Points (for exam)
Uses LinkedList<String>

Iterator → forward display

ListIterator → reverse display

Q17. Write a java program to solve producer consumer problem in which a producer 
produces a value and consumer consume the value before producer generate the next 
value. (Use thread synchronization) 


short and easy without skipping any line

Here is a short and easy Java program for Producer–Consumer using thread synchronization (complete, no lines skipped):

✅ Java Program: Producer Consumer Problem
class Shared {
    int value;
    boolean flag = false;

    synchronized void produce(int v) {
        try {
            if (flag)
                wait();

            value = v;
            System.out.println("Produced: " + value);

            flag = true;
            notify();

        } catch (Exception e) {
            System.out.println(e);
        }
    }

    synchronized void consume() {
        try {
            if (!flag)
                wait();

            System.out.println("Consumed: " + value);

            flag = false;
            notify();

        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

class Producer extends Thread {
    Shared s;

    Producer(Shared s) {
        this.s = s;
    }

    public void run() {
        int i = 1;
        while (true) {
            s.produce(i++);
            try {
                Thread.sleep(1000);
            } catch (Exception e) {
                System.out.println(e);
            }
        }
    }
}

class Consumer extends Thread {
    Shared s;

    Consumer(Shared s) {
        this.s = s;
    }

    public void run() {
        while (true) {
            s.consume();
            try {
                Thread.sleep(1000);
            } catch (Exception e) {
                System.out.println(e);
            }
        }
    }
}

public class ProducerConsumerDemo {
    public static void main(String[] args) {
        Shared s = new Shared();

        Producer p = new Producer(s);
        Consumer c = new Consumer(s);

        p.start();
        c.start();
    }
}

Uses synchronized methods

Uses wait() and notify()

flag controls production/consumption

Producer produces → Consumer consumes → repeat

Ensures no overwrite before consumption

Q21. Write a Servlet program to display number of times user has visited the page. (Use 
cookies)
short and easy without skipping any line

Here is a short and easy Servlet program using Cookies (complete, no lines skipped):

✅ Servlet Program (VisitServlet.java)
import java.io.*;
import javax.servlet.*;
import javax.servlet.http.*;

public class VisitServlet extends HttpServlet {

    public void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {

        response.setContentType("text/html");
        PrintWriter out = response.getWriter();

        int count = 0;

        // Get Cookies
        Cookie[] cookies = request.getCookies();
        boolean found = false;

        if (cookies != null) {
            for (int i = 0; i < cookies.length; i++) {
                if (cookies[i].getName().equals("count")) {
                    count = Integer.parseInt(cookies[i].getValue());
                    found = true;
                    break;
                }
            }
        }

        if (found) {
            count++;
        } else {
            count = 1;
        }

        // Create/Update Cookie
        Cookie c = new Cookie("count", String.valueOf(count));
        response.addCookie(c);

        // Display Count
        out.println("<h2>You have visited this page " + count + " times</h2>");
    }
}
🧠 Important Points (for exam)
Uses Cookie to store visit count

request.getCookies() to read cookies

response.addCookie() to update cookie

Count increases on every visit

First visit → count = 1

public class SessionVisitServlet extends HttpServlet {

    public void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {

        response.setContentType("text/html");

        out.println("<h2>You have visited this page " + count + " times</h2>");
    }
