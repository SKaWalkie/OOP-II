# ✅ Q1. Thread Program (A to Z every 2 seconds, priority = 8)

```java
class AlphabetThread extends Thread {
    public void run() {
        for (char c = 'A'; c <= 'Z'; c++) {
            System.out.print(c + " ");
            try {
                Thread.sleep(2000); // 2 seconds
            } catch (InterruptedException e) {
                System.out.println(e);
            }
        }
    }
}

public class Q1 {
    public static void main(String[] args) {
        AlphabetThread t = new AlphabetThread();
        t.setPriority(8); // set priority
        t.start();
    }
}
```

# ✅ Q2. JDBC Program (Insert + Display Employee)

### 🗄️ Assumption:

* Database: MySQL
* Table:

```sql
CREATE TABLE Employee (
    Eno INT,
    EName VARCHAR(50),
    Designation VARCHAR(50),
    Salary DOUBLE
);
```

---

## 🔹 Java Code:

```java
import java.sql.*;
import java.util.Scanner;

public class Q2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        try {
            // Load driver
            Class.forName("com.mysql.cj.jdbc.Driver");

            // Connection
            Connection con = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/test", "root", "password");

            // Accept input
            System.out.print("Enter Eno: ");
            int eno = sc.nextInt();
            sc.nextLine();

            System.out.print("Enter Name: ");
            String name = sc.nextLine();

            System.out.print("Enter Designation: ");
            String desig = sc.nextLine();

            System.out.print("Enter Salary: ");
            double sal = sc.nextDouble();

            // Insert
            PreparedStatement ps = con.prepareStatement(
                "INSERT INTO Employee VALUES (?, ?, ?, ?)");
            ps.setInt(1, eno);
            ps.setString(2, name);
            ps.setString(3, desig);
            ps.setDouble(4, sal);
            ps.executeUpdate();

            System.out.println("Inserted Successfully!\n");

            // Display
            Statement st = con.createStatement();
            ResultSet rs = st.executeQuery("SELECT * FROM Employee");

            while (rs.next()) {
                System.out.println(
                    rs.getInt(1) + " " +
                    rs.getString(2) + " " +
                    rs.getString(3) + " " +
                    rs.getDouble(4)
                );
            }

            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}
```

## Q2. Servlet Visit Counter (Cookie)

```java
import java.io.*;
import javax.servlet.*;
import javax.servlet.http.*;

public class VisitServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse res)
    throws IOException {

        PrintWriter out = res.getWriter();
        Cookie[] c = req.getCookies();

        int count = 1;

        if(c!=null){
            for(Cookie ck:c){
                if(ck.getName().equals("visit")){
                    count = Integer.parseInt(ck.getValue())+1;
                }
            }
        }

        res.addCookie(new Cookie("visit", String.valueOf(count)));

        if(count==1)
            out.println("Welcome First Time");
        else
            out.println("Visited "+count+" times");
    }
}
```

## Q2. Producer Consumer

```java
class PC {
    int n;
    boolean flag=false;

    synchronized void produce(int x) throws Exception {
        if(flag) wait();
        n=x;
        System.out.println("Produced "+n);
        flag=true;
        notify();
    }

    synchronized void consume() throws Exception {
        if(!flag) wait();
        System.out.println("Consumed "+n);
        flag=false;
        notify();
    }
}

public class Q2 {
    public static void main(String[] args) {
        PC pc = new PC();

        new Thread(() -> {
            try {
                for(int i=1;i<=5;i++)
                    pc.produce(i);
            } catch(Exception e){}
        }).start();

        new Thread(() -> {
            try {
                for(int i=1;i<=5;i++)
                    pc.consume();
            } catch(Exception e){}
        }).start();
    }
}
```
