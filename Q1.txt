


Q1. Write a Java program to display all the alphabets between ‘A’ to ‘Z’ after every 2 
seconds. Change the priority of the thread to 8.

short and easy without skipping any line

Here is a short and complete Java program that prints A–Z with a 2-second delay and sets thread priority to 8:

class AlphabetThread extends Thread
{
    public void run()
    {
        for(char ch = 'A'; ch <= 'Z'; ch++)
        {
            System.out.println(ch);
            try
            {
                Thread.sleep(2000); // 2 seconds delay
            }
            catch(Exception e)
            {
                System.out.println(e);
            }
        }
    }
}

class Main
{
    public static void main(String args[])
    {
        AlphabetThread t = new AlphabetThread();

        t.setPriority(8); // set priority to 8

        t.start(); // start thread
    }
}
Key Points:
Thread.sleep(2000) → pauses for 2 seconds

setPriority(8) → changes thread priority

Loop prints characters from 'A' to 'Z'

Q4. Write a Java program to store city names and their STD codes using an appropriate 
collection and perform following operations:  
i. Add a new city and its code (No duplicates)  
ii. Search for a city name and display the code.  

short and easy without skipping any line

Here is a short and complete Java program using HashMap:

import java.util.*;

class Main
{
    public static void main(String args[])
    {
        Scanner sc = new Scanner(System.in);

        HashMap<String, String> map = new HashMap<String, String>();

        System.out.print("Enter number of cities: ");
        int n = sc.nextInt();
        sc.nextLine();

        for(int i = 0; i < n; i++)
        {
            System.out.print("Enter city name: ");
            String city = sc.nextLine();

            if(map.containsKey(city))
            {
                System.out.println("City already exists");
                i--;
            }
            else
            {
                System.out.print("Enter STD code: ");
                String code = sc.nextLine();
                map.put(city, code);
            }
        }

        System.out.print("Enter city to search: ");
        String searchCity = sc.nextLine();

        if(map.containsKey(searchCity))
        {
            System.out.println("STD Code: " + map.get(searchCity));
        }
        else
        {
            System.out.println("City not found");
        }
    }
}
Key Points:
HashMap → stores city (key) and STD code (value)

containsKey() → prevents duplicates & helps in search

put() → adds data

get() → retrieves STD code

If needed, I can also give a version using TreeMap (sorted cities).

{

        ArrayList<String> list = new ArrayList<String>();

            System.out.println("After removal:");

            for(String s : list)
            {
                System.out.println(s);
            }
        }
        else
        {
            System.out.println("Invalid index");
        }
    }

Q24. Write program to create a link list of integer objects. Perform following operations on 
link list. 
 i. Add element at first position 
 ii. Display the size of link list

short and easy without skipping any line

Here is a short and complete Java program using LinkedList:

import java.util.*;

class Main
{
    public static void main(String args[])
    {
        Scanner sc = new Scanner(System.in);

        LinkedList<Integer> list = new LinkedList<Integer>();

        System.out.print("Enter number of elements: ");
        int n = sc.nextInt();

        System.out.println("Enter integers:");

        for(int i = 0; i < n; i++)
        {
            int num = sc.nextInt();
            list.addFirst(num); // add at first position
        }

        System.out.println("LinkedList elements:");

        for(int x : list)
        {
            System.out.println(x);
        }

        System.out.println("Size of LinkedList: " + list.size());
    }
}
Key Points:
addFirst() → adds element at first position

size() → returns number of elements

LinkedList<Integer> → stores integer objects

Q25. Write JDBC program to check database connection to Emp table (Eno, ename, salary). 
Display appropriate message. 

short and easy without skipping any line

Here is a short and complete JDBC program to check database connection:

import java.sql.*;

class Main
{
    public static void main(String args[])
    {
        try
        {
            Class.forName("com.mysql.cj.jdbc.Driver");

            Connection con = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/test", "root", "root");

            Statement st = con.createStatement();

            ResultSet rs = st.executeQuery("SELECT * FROM Emp");

            if(rs.next())
            {
                System.out.println("Connection successful. Data found in Emp table.");
            }
            else
            {
                System.out.println("Connection successful. No data in Emp table.");
            }

            con.close();
        }
        catch(Exception e)
        {
            System.out.println("Connection failed");
            System.out.println(e);
        }
    }
}
Key Points:
Class.forName() → loads JDBC driver

DriverManager.getConnection() → establishes connection

executeQuery() → runs SQL query

rs.next() → checks if table has data
