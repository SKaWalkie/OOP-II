## 1. Thread A–Z every 2 seconds (priority = 8)

```java
class AlphaThread extends Thread {
    public void run() {
        for(char c='A'; c<='Z'; c++) {
            System.out.println(c);
            try { Thread.sleep(2000); } catch(Exception e){}
        }
    }
    public static void main(String[] args) {
        AlphaThread t = new AlphaThread();
        t.setPriority(8);
        t.start();
    }
}
```

## 2. HashSet friends → ascending order

```java
import java.util.*;
class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(); sc.nextLine();
        HashSet<String> set = new HashSet<>();

        for(int i=0;i<n;i++) set.add(sc.nextLine());

        TreeSet<String> sorted = new TreeSet<>(set);
        System.out.println(sorted);
    }
}
```

## 6. Reverse 100→1 thread sleep + name

```java
class Rev extends Thread {
    public void run() {
        for(int i=100;i>=1;i--) {
            System.out.println(i);
            try { Thread.sleep(2000);} catch(Exception e){}
        }
    }
    public static void main(String[] args) {
        Rev t = new Rev();
        t.setName("reverse order");
        t.start();
    }
}
```

## 7. 3 Threads printing text

```java
class MyThread extends Thread {
    String msg; int n;
    MyThread(String m,int n){ msg=m; this.n=n; }

    public void run() {
        for(int i=0;i<n;i++) System.out.println(msg);
    }

    public static void main(String[] args) {
        new MyThread("COVID19",10).start();
        new MyThread("LOCKDOWN2020",20).start();
        new MyThread("VACCINATED2021",30).start();
    }
}
```

## 19. Vowels every 3 sec

```java
class T extends Thread {
    String s;
    T(String s){this.s=s;}

    public void run(){
        for(char c:s.toCharArray()){
            if("aeiouAEIOU".indexOf(c)!=-1){
                System.out.println(c);
                try{Thread.sleep(3000);}catch(Exception e){}
            }
        }
    }
    public static void main(String[] args){
        new T("Education").start();
    }
}
```
